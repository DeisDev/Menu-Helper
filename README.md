# Menu Helper

An F4SE plugin that lets mods add entries, settings pages, text pages and dialogs to the Fallout 4 main menu and pause menu. Mods use it from an F4SE plugin, from Papyrus, or with a JSON file. It uses the game's own panels and replaces no vanilla files.

Requires Fallout 4 1.11.240 (Steam), F4SE 0.7.9 or later, and Address Library for F4SE.

## Install

Copy the `Data` folder from the release archive into the game folder, or install the archive with a mod manager.
