# Menu Helper

Menu Helper lets mods add entries, settings pages, text pages and dialogs to the Fallout 4 main menu and pause menu. It uses the game's own panels and replaces no vanilla files.

Mods can use it from:

- an F4SE plugin: [Plugin API](https://github.com/DeisDev/Menu-Helper/wiki/Plugin-API)
- Papyrus: [Papyrus](https://github.com/DeisDev/Menu-Helper/wiki/Papyrus)
- a JSON file, no code: [JSON Menus](https://github.com/DeisDev/Menu-Helper/wiki/JSON-Menus)

Requires Fallout 4 1.11.240 (Steam), F4SE 0.7.9 or later, and Address Library for F4SE.
